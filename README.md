# loomground-factual

The **factual / assertoric** language plane of the Loomground family. It lowers
free-text assertions into the fixed five-dimensional (5D) representation —
relational and structural edges — that the modal languages evaluate against. It
is the alethic *substrate*: the plane that says *what is the case*, over which
the deontic (ought), epistemic (know/believe), and legal planes reason.

Standard-library only. It is a leaf: it depends on no other Loomground plane at
runtime, and grows no reasoning of its own — composition and grounded reasoning
live on `loomground-solver`, the modal vocabularies on their own planes.

## Install

```sh
pip install "loomground-factual @ git+https://github.com/flxk1/loomground-factual@<commit>"
```
